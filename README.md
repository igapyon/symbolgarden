# symbolgarden

`symbolgarden` は、ロゴ、シンボル、OGP 画像素材をまとめたリポジトリです。

## 構成

- `symbols/`
  - カテゴリ別の SVG シンボル集
  - `business/`, `generic/`, `music/`, `technology/`
- `wordmarks/`
  - ロゴやワードマークの SVG
- `ogp/`
  - OGP 用の画像素材
  - `*.png` と編集元の `*.pptx`

## 命名

- シンボル: `*-symbol.svg`
- ロゴ: `*-logo.svg`
- OGP 画像: `*-ogp.png`
- OGP 編集元: `*-ogp.pptx`

## 収録形式

- SVG
- PNG
- PPTX
